
## VRAM Management
- Load one model at a time (8GB constraint)
- 5-second cooldown between swaps
- Queue requests when swapping
- Track loaded model in ModelManager

## Notes
- All models use Q4_K_M quantization for 8GB VRAM
- Nemotron-3-Nano may use different quantization (MoE)
- Can run larger models with CPU offloading (slower)
- Monitor VRAM usage: nvidia-smi
