What Happened?

This study set out to prove that multi-agent ensemble techniques could beat individual vision models for OCR. The hypothesis was wrong.

We tested three ensemble strategies—Weighted Voting, Escalation Chain, and Socratic Debate—against extreme image degradations. The expectation was that combining multiple models would recover accuracy lost by any single model.

Instead, Qwen2.5-VL running alone achieved 77% accuracy, while the best ensemble technique (Socratic Debate) only managed 41%—a 47% decrease.

Why Did Ensemble Fail?

1. Massive Quality Gap Between Models

Qwen2.5-VL (77%) is nearly 4x more accurate than LLaVA (20%). Ensemble methods assume models make different errors—but when one model is consistently wrong, it corrupts the consensus.

2. "Democracy" With Incompetent Voters

In weighted voting, LLaVA (15% weight) and MiniCPM (35% weight) together outweigh Qwen's vote. Two weak models agreeing on a wrong answer can outvote the correct one. Majority rule fails when most voters are wrong.

3. Alignment Algorithm Corruption

When models produce wildly different text (e.g., "INVOICE #2847" vs "INVOCE #2B47" vs "lnv0ice"), character-level alignment introduces spurious gaps and misalignments. This scrambles the consensus-building process.

4. Garbage In, Garbage Out

LLaVA consistently produced 0-55% accuracy—essentially random text on degraded images. Including its "votes" is like asking someone who can't read to help transcribe a document.

The Honest Conclusion

For OCR on this hardware (8GB VRAM), just use Qwen2.5-VL 7B alone.

Ensemble methods only work when participating models have:

  • Similar accuracy levels (within ~10-15%)
  • Different error patterns (uncorrelated mistakes)
  • Complementary strengths (one handles blur, another handles noise)

Here, Qwen is so much better than the others that adding teammates just slows it down and introduces errors.

Recommendation

Use Qwen2.5-VL 7B as the sole OCR engine.

If ensemble is still desired, exclude LLaVA entirely and only use Qwen + MiniCPM with heavily Qwen-weighted voting (80%+ weight to Qwen).

When Would Ensemble Work?

Ensemble OCR would outperform individual models if:

  • All models had 70%+ baseline accuracy
  • Models made different types of errors (Qwen misreads "5/S", MiniCPM misreads "0/O")
  • Confidence thresholds filtered out low-quality outputs
  • Multiple instances of the same strong model with different prompts

A promising alternative: Run Qwen2.5-VL twice with different prompts ("transcribe exactly" vs "read and correct obvious errors") and vote between its own outputs.
