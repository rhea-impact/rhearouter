# Claude Code Guidelines for RheaRouter

## System Package Installation

When you need to install system packages (like `gh`, `jq`, etc.), **DO NOT** just download binaries with curl and extract them to `~/bin`.

**Instead, use `sudo -A` to properly install packages:**

```bash
# Good - Uses package manager with sudo -A
sudo -A apt install gh

# Bad - Manual binary installation
curl -L https://github.com/cli/cli/releases/latest/download/gh.tar.gz | tar xz
cp gh_*/bin/gh ~/bin/
```

### Why Use `sudo -A`?

1. **Proper System Integration** - Package managers handle dependencies, PATH configuration, and updates
2. **Security** - Packages are verified and signed
3. **Maintainability** - Easy to upgrade and remove
4. **Standard Locations** - Binaries go to `/usr/bin` where they belong

### When `sudo -A` Is Not Available

If the environment doesn't support `sudo -A` (no askpass helper configured), then you can fall back to manual installation, but this should be the exception, not the rule.
